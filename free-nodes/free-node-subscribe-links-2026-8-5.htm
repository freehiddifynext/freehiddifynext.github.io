第一章：认识你的数字卫士

Thor：加密迷宫的建筑师

想象Thor如同建造了一座由镜面组成的迷宫，任何试图追踪你的数字足迹的窥探者都会在其中迷失方向。这款基于顶级加密技术的工具通过多重服务器跳转（通常称为"洋葱路由"原理）将你的网络请求包裹在层层加密中。不同于普通VPN仅提供单点加密，Thor的动态路径选择让流量如同量子粒子般难以捉摸——即使某个节点被攻破，攻击者看到的也只是一段无法解密的乱码和下一个随机选择的节点地址。

其全球服务器网络覆盖60多个国家/地区，每个节点都采用军事级AES-256加密。特别值得注意的是其"混淆服务器"功能，能让你在严格网络审查的地区（如某些中东国家）也能伪装成普通HTTPS流量，成功突破网络封锁。

Shadowrocket：网络流量的智能调度员

如果说Thor是重型装甲车，那么Shadowrocket就是精确的GPS导航系统。这款iOS平台的神器支持SS/SSR/V2Ray/Trojan等多种协议，其独创的"规则分流"功能可智能判断哪些流量需要加密（如访问境外网站），哪些可以直接连接（如本地视频流媒体）。通过细致的分流设置，用户既能享受加密安全，又不会因全程VPN导致的网速下降影响观看4K视频的体验。

其仪表盘设计堪称艺术品——实时显示上下行速度、延迟、数据消耗量的同时，还能以时间轴形式展示历史连接记录。当检测到异常流量时（如某个应用在后台大量传输数据），会立即弹出警示，堪称移动端的网络安全卫士。

FAQ

Nekoray 节点订阅更新不成功怎么办？
检查订阅 URL 是否有效并确保网络通畅。可手动刷新或重新添加订阅链接，保证节点列表最新。结合策略组使用，确保稳定科学上网体验。
Netch 的 TAP 模式与 TUN 模式区别是什么？
TAP 模式模拟以太网接口，适合游戏流量代理；TUN 模式则模拟 IP 层接口，更适合全局代理。根据用途不同可自由选择，但需管理员权限运行。
Mihomo 的节点分组管理有哪些优势？
节点分组可按用途、地区或延迟分类，结合策略组实现自动分流。方便用户管理大量节点，快速选择最佳节点，提高访问速度和连接稳定性，同时优化维护效率。
Trojan 的证书配置错误会导致什么问题？
如果 TLS 证书无效或域名不匹配，Trojan 客户端将无法建立安全连接，导致节点无法使用。需要确保证书有效、域名正确，才能保证正常访问。
V2Ray 的 DNS 模块如何提升解析速度？
V2Ray 内置 DNS 模块支持并行解析，可同时请求多个上游 DNS 服务器。用户可配置本地优先解析或远程解析策略，从而减少域名污染与延迟问题。
如何在 Nginx 上为 Vmess/WS 配置反向代理与 TLS？
在 Nginx 中配置 HTTPS 站点并将特定路径（如 /ray）反向代理到 V2Ray 的 WebSocket 端口，确保 proxy_set_header 设置正确（Host、X-Real-IP 等）。同时使用 certbot 获取并自动续期 TLS 证书以维护安全。
Nekobox 是否支持自定义 DNS 解析？
支持。用户可以在配置中指定 DNS 服务器或启用 DoH/DoT 功能，确保域名解析安全和快速，避免本地 DNS 污染或被劫持。
Hiddify Next 的用户管理可以分组吗？
支持用户分组管理，可为不同组设置独立带宽、流量配额和节点访问权限。分组管理便于大规模用户维护，确保每个组的网络资源合理分配，提升整体管理效率。
Mellow 的 TUN 模式是否支持全局游戏加速？
支持。TUN 模式拦截系统 IP 层流量，实现全局代理，确保游戏和其他应用的 UDP/TCP 流量都走代理节点，从而降低延迟，提高游戏体验。
当 V2Ray 报错 inbound 没有监听，可能是哪些配置问题？
检查 inbound 配置是否包含正确的 port、protocol 与 listen 字段；确认没有端口冲突或权限问题（非 root 绑定 1024 以下端口会失败）；查看日志中具体错误信息并根据提示修复配置。
